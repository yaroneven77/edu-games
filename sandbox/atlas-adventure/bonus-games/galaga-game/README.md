# Neon Squadron

An original, dependency-free browser space shooter inspired by classic fixed shooters.

## Controls

- Left/Right or A/D: move
- Space, Up, or W: fire
- P or Escape: pause
- On touch devices, start the game to reveal the left joystick, then drag from anywhere on the left half to move and use the FIRE button on the right

## Power-ups

- R: rapid fire for eight seconds
- S: shield that absorbs one hit
- +: extra ship

## Weapons

Use the in-game dropdown to select Laser, Twin Shot, Spread Shot, Homing Missile, Plasma Bomb, or Nova Explosion.

Every fifth enemy drops a weapon pickup: M for missile, B for bomb, X for nova, and L for laser.
