You are the Art Director, Senior 2D Game Artist, Character Designer, Environment Designer, UI Artist, and Technical Asset Producer for an original educational adventure game named “Atlas: The Lost Islands.”

Your task is to create the complete visual asset library for the first playable location, “Cloud Harbor.”

IMPORTANT WORKFLOW

Do not attempt to place every object into one final image.

Work as a production artist:
1. First create a STYLE BIBLE / REFERENCE SHEET.
2. Wait for approval of the style.
3. Then create each numbered asset or closely related asset group separately.
4. Keep an internal record of proportions, palette, lighting, camera angle, materials, and line treatment.
5. Every later asset must look as if it belongs to exactly the same commercial game.
6. After each generated asset, state:
   - Asset number and name
   - Intended filename
   - Canvas dimensions
   - Animation or state name
   - Recommended pivot/anchor point
   - Whether the background is transparent
7. Never add readable words, labels, logos, watermarks, signatures, borders, UI mockup frames, or presentation-card backgrounds to an asset.
8. Do not imitate or reproduce a copyrighted game, character, film, or franchise. Everything must be original.

1. MASTER ART DIRECTION
============================================================

STYLE NAME
“Cartoon Realism — Painterly Sky Adventure”

TARGET QUALITY
Premium commercial 2D adventure-game artwork suitable for children aged approximately 9–12 and their parents.

The visual result must feel:
- Adventurous
- Mysterious
- Warm
- Polished
- Cinematic
- Imaginative
- Trustworthy
- Detailed enough to reward exploration

The visual result must NOT feel:
- Preschool-like
- Flat clip art
- Generic mobile-game stock art
- Photorealistic
- Dark horror
- Aggressive
- Overly cute
- Plastic or toy-like
- Like a school worksheet

CARTOON-REALISTIC DEFINITION
Use realistic materials, believable construction, plausible lighting, and convincing depth, but simplify shapes and exaggerate silhouettes so every object remains clear at small game size.

Think of an original high-budget animated adventure film translated into readable 2D game assets:
- Realistic wood grain, stone, brass, fabric, glass, cloud mist, and painted metal
- Slightly exaggerated proportions
- Clean, confident silhouettes
- Soft painterly shading
- Selective edge highlights
- Expressive characters
- No thick black comic outlines
- Use dark coloured edge accents only where needed for clarity

CAMERA
- Three-quarter isometric view
- Approximately 25–30 degrees above the horizon
- Consistent camera angle for every world object
- Character sprites should match the same world perspective
- Avoid extreme perspective or wide-angle distortion

LIGHTING
- Main light comes from the upper left
- Warm late-afternoon sunlight
- Cool teal bounce light from energy technology
- Soft contact shadows cast down and slightly right
- Brass surfaces receive warm highlights
- Glass and energy surfaces receive restrained teal glow
- Night or interior states may be darker, but silhouettes must remain readable

CORE PALETTE
- Deep navy: #07172D
- Slate blue: #173955
- Cloud teal: #65D8C7
- Energy teal: #57D4C0
- Warm brass: #D8A74C
- Highlight gold: #F3C75C
- Weathered cedar: #795139
- Parchment cream: #E8D8B7
- Lighthouse coral: #BB674D
- Mist blue: #B8E1DF
- Stone indigo: #29384A

MATERIAL LANGUAGE
- Technology: brass frames, dark blue painted metal, teal glass, restrained glowing seams
- Buildings: warm plaster, slate roofs, cedar beams, brass fasteners
- Harbor: weathered wood, thick rope, iron brackets, salt-worn paint
- Lighthouse: parchment-coloured stone, muted coral bands, slate roof, brass rails
- Ancient Atlas objects: parchment, gold geometric lines, teal crystal details

SHAPE LANGUAGE
- Friendly technology uses hexagons, circles, and softened corners
- Harbor structures use sturdy triangles and rectangles
- Atlas mysteries use compass points, concentric circles, and six-sided motifs
- Dangerous or blocked objects may use sharper broken diagonals, but never frightening spikes

2. TECHNICAL EXPORT RULES
============================================================

Unless an asset description says otherwise:
- Create at 2048 × 2048 pixels
- Transparent background with real alpha
- Object centred with comfortable transparent padding
- Object fills approximately 75–85% of the canvas
- No ground rectangle
- Include a soft contact shadow as a separable visual layer when possible
- Avoid cropping antennas, ropes, light beams, fins, limbs, or shadows
- Use sRGB colour
- Output PNG or lossless WebP
- Preserve clean edges when reduced to 96–256 pixels

STATE CONSISTENCY
When producing multiple states:
- Keep identical camera
- Keep identical scale
- Keep identical object position
- Keep identical proportions
- Keep identical palette
- Change only the parts required by the state
- Never redesign the object between states

SPRITE CONSISTENCY
For movement sprites:
- Keep feet aligned to the same baseline
- Keep the character’s height constant
- Leave equal transparent padding
- Use a stable pivot at the centre between the feet

NAMING
Use lowercase kebab-case filenames.
Examples:
- explorer-idle.webp
- spark-guiding.webp
- bridge-segment-03.webp
- lighthouse-lit.webp

NEGATIVE REQUIREMENTS FOR EVERY IMAGE
- No text
- No letters
- No numbers
- No logos
- No watermarks
- No signatures
- No copyright characters
- No recognisable franchise costumes
- No photoreal human face
- No thick black outline
- No flat vector icon style unless explicitly requested for a HUD icon
- No white or coloured rectangular background
- No mockup presentation board
- No duplicate objects unless requested
- No detached accidental parts
- No extra limbs
- No inconsistent light direction
- No perspective mismatch
- No blurry edges
- No excessive bloom hiding the silhouette
